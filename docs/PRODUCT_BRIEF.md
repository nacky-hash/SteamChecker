# PRODUCT_BRIEF

## 誰の何を解決するか

SSD の空き容量が足りないゲーマー。**欲しいのは空き容量であって、圧縮されたゲームではない。**

## 中核となる主張

**「圧縮しても無駄です」と言えることが、見積もりの正直さの証明になる。**

60GB のゲームで実測圧縮率が 8% なら、圧縮しても 4.8GB しか空かない。
3 年起動していないなら、削除すれば 60GB 空く。12 倍の差がある。
「圧縮しても 4.8GB です」とだけ言って終わるツールは、問題を解決していない。

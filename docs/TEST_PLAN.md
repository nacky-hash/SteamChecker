## テスト実行

```bash
dotnet test                                        # NuGet あり
dotnet run --project tests/SteamChecker.TestRunner # NuGet に到達できない環境
```

`TestRunner` は xUnit 互換シムを持つ依存ゼロのランナー。
テストの `.cs` は 1 か所のまま、両方から実行できる。二重管理はしない。

## 安全側の検査（2026-07-30 実装。実装は `Core/Compression/PreFlight.cs`、テストは `PreFlightTests.cs`）

| 検査 | テスト方法 | 状態 |
|---|---|---|
| 対象が検出済み Steam ライブラリ配下か | パストラバーサルを含む manifest を食わせて拒否を確認 | **実装・テスト済み**（`SteamReaderTests` / `PreFlightTests`） |
| manifest が現在も存在するか | 走査中に削除されるケース（TOCTOU） | **実装・テスト済み** |
| ファイルシステムが NTFS か | FakeFileSystem で exFAT / 判定不能を再現 | **実装・テスト済み**。E: (exFAT) での実地確認は未実施 |
| 親/子階層に reparse point がないか | 親・子・対象自身の3パターン。※圧縮済み判定には使わない（D-005） | **実装・テスト済み**。実ジャンクションでの実地確認は未実施 |
| Steam クライアントが起動中でないか | プロセス名の検出（一覧が取れない場合も Block） | **実装・テスト済み** |
| ゲーム内の実行ファイルが起動中でないか | 排他オープンによるロック検出 | **実装・テスト済み**（ロック判定はデリゲート注入。実ロックでの実地確認は未実施） |
| DirectStorage DLL の兆候 | `dstorage*.dll` の配置。Warn のみ（兆候なし＝安全とは表示しない） | **実装・テスト済み** |
| 容量測定エラー | 測定不能（合計 0）で Block | **実装・テスト済み**。`GetCompressedFileSizeW` 失敗系は論理サイズへのフォールバックで吸収 |
| 圧縮・解除に必要な空き容量 | 最大ファイル + 余裕分の空きを要求。不足・不明で Block | **実装・テスト済み** |
| **失敗時にゲームデータを削除しない** | キャンセル注入 → 全ファイルの SHA-256 不変を確認（Windows では実 compact.exe） | **実装・テスト済み**（`CompactExeEngineTests`。Windows 以外では検証をスキップして通る点に注意） |

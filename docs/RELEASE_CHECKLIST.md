# RELEASE_CHECKLIST

## Phase 0（読み取り専用）を出すまで

- [ ] .NET SDK 10 を導入し、`dotnet build` / `dotnet test` が通ること
- [ ] `dotnet publish -r win-x64 --self-contained` が通ること
- [ ] SmartScreen で何が出るか自分の環境で確認し、README に正直に書く
- [ ] ソース公開（MIT）。再現可能ビルドの手順を README に書く
- [ ] リリース成果物の SHA-256 を公開する
- [ ] 署名方針を明記する（無署名なら「無署名である」と書く。ごまかさない）
- [ ] 通信ゼロであることを、コードのどこを見れば確認できるか README に書く
- [ ] スクリーンショットに実在のユーザー名・Steam ID・フルパスが写っていないこと
- [ ] 「必ず N% 削減」「性能低下なし」といった表現が一切ないこと

## Phase 1（圧縮実行）を出すまで

- [ ] Phase 0 の全項目
- [ ] `docs/TEST_PLAN.md` の安全側の検査が全てテスト付きで実装済み
- [ ] 中断・失敗時にゲームデータが破損しないことをテストで保証
- [ ] 操作ログにユーザー名・Steam ID・フルパスが残らないこと
- [ ] UAC 昇格のフォールバック（常時要求はしない）
- [ ] 実ゲームでの圧縮→起動確認を、再ダウンロード可能な小容量タイトルで実施

## 配布判定

**配布不可 / 開発者限定テスト可 / 少人数アルファ可 / 一般ベータ可** のいずれかを、
根拠と残存リスクを添えて明示する。楽観的に判定しない。
